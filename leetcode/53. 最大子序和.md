
- 找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和
- 例如[1,-3,4,-1,2,1,-5]，输出6

### 1. 动态规划
dp   时间复杂度 O(n),空间复杂度O(1)
- 好理解的版本：
```java
class Main {
    public static int maxSubNum(int[] arr){
        int n = arr.length;
        if(n == 0) return 0;
        int[] endDP = new int[n];
        endDP[0] = arr[0];
        int[] maxSum = new int[n];
        maxSum[0] = arr[0];
        for(int i = 1;i<n;i++){
            endDP[i] = Math.max(endDP[i-1]+arr[i], arr[i]);
            maxSum[i] = Math.max(endDP[i], maxSum[i-1]);
        }
        return maxSum[n-1];
    }
    public static void main(String[] args) {
        System.out.println("Hello, World!"); 
//        int[] arr = new int[3];
//        arr[0] = 2;
//        arr[1] = 1;
//        arr[2] =-5;
        int[] arr = {1,-3,4,-1,2,1,-5};
        System.out.println(maxSubNum(arr)); 
    }
}
```

- 浓缩版代码：
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int pre = nums[0];
        int max = nums[0];
        for(int i =1;i<nums.length;i++){
            pre = Math.max(nums[i],pre+nums[i]);
            max = Math.max(pre,max);
        }
        return max;
    }
}
```
```java
public int maxSubArray(int[] nums) {
    int sum = nums[0],max = nums[0];
    for(int i = 1; i < nums.length;i++){
        if(sum < 0){
            sum = nums[i];
        }else{
            sum += nums[i];
        }
        max = Math.max(max, sum);
    }
    return max;
}
```
```c++
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int ans = nums[0];
        int n = (int)nums.size();
        int pre = 0;
        for(const auto &x:nums){
            //子串
            pre = max(pre+x, x);
            //总的与子串比较
            ans = max(ans, pre);
        }
        return ans;
    }
};
```

### 2. 分治
max(left,right,cross)
时间复杂度O(nlogn),空间复杂度O(logn)

```java
public int maxSubArray(int[] nums) {
    int len = nums.length;
    if(len == 0) return 0;
    return maxSubArraySum(nums, 0, len-1);
}
public int maxSubArraySum(int[] nums, int left, int right){
    if(left == right) return nums[left];
    int mid = left + (right - left)/2;
    return Math.max(maxSubArraySum(nums, left, mid),Math.max(maxSubArraySum(nums, mid+1, right),crossMaxSum(nums,left, mid, right)));
}
public int crossMaxSum(int[] nums, int left, int mid, int right){
    //left - mid max
    int sum = 0;
    int leftMax = Integer.MIN_VALUE;
    for(int i = mid;i>=left;i--){
        sum += nums[i];
        if(sum>leftMax){
            leftMax = sum;
        }
    }
    int rightMax = Integer.MIN_VALUE;
    sum = 0;
    for(int i = mid+1;i<=right;i++){
        sum += nums[i];
        if(sum > rightMax) rightMax = sum;
    }
    //mid + 1 right max
    return leftMax + rightMax;
}
```
