Max Tree
Given an integer array with no duplicates. A max tree building on this array is defined as follow:

The root is the maximum number in the array
The left subtree and right subtree are the max trees of the subarray divided by the root number.
Construct the max tree by the given array.

Example
Example 1:

Input：[2, 5, 6, 0, 3, 1]
Output：{6,5,3,2,#,0,1}
Explanation：
the max tree constructed by this array is:

    6
/ \
5   3
/   / \
2   0   1

# 三、最优解法（重点）：单调栈 O(n)
🔥 核心思想
对数组中 每个元素：
找它 左边第一个比它大的数
找它 右边第一个比它大的数
较小的那个，作为它的父节点
最大值没有更大的数 → 它就是根
这和你前面做过的 单调栈 / Next Greater Element 是同一类问题。

关键不变量
栈内元素 单调递减
每个元素出栈时：
它左右两边第一个更大的元素已确定
父节点 = 左右更大元素中较小的那个
这正好符合 Max Tree 的定义：
父节点一定是 离自己最近、但比自己大的数
```java
import java.util.*;

public class Solution {

    public TreeNode maxTree(int[] A) {
        if (A == null || A.length == 0) return null;

        int n = A.length;
        TreeNode[] nodes = new TreeNode[n];
        for (int i = 0; i < n; i++) {
            nodes[i] = new TreeNode(A[i]);
        }

        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i <= n; i++) {
            int curVal = (i == n) ? Integer.MAX_VALUE : A[i];

            while (!stack.isEmpty() && A[stack.peek()] < curVal) {
                int idx = stack.pop();
                if (stack.isEmpty()) {
                    if (i < n) {
                        nodes[i].left = nodes[idx];
                    }
                } else {
                    int leftIdx = stack.peek();
                    if (i < n && A[leftIdx] > curVal) {
                        nodes[i].left = nodes[idx];
                    } else {
                        nodes[leftIdx].right = nodes[idx];
                    }
                }
            }
            stack.push(i);
        }

        return nodes[stack.peek()];
    }
}
```
